# Contributing to Miauflix

Contributions are welcome and appreciated!

1. Fork the repository and create a feature branch from `main`.
2. Set up your environment with the [Development Workflow](docs/development/workflow.md) guide.
3. Follow the [coding conventions](docs/development/coding-conventions.md) and the [testing guide](docs/development/testing-guide.md).
4. Make sure `npm run build`, `npm run lint` and the tests pass.
5. Open a pull request with a clear description of the change.

Tests run without network access, using recorded fixtures. See the [CI/CD Guide](docs/development/ci-cd-guide.md) for details.
