# Languages, translation, and learning

[Back to all features](../features.md)

This group describes **planned work** from [ToDo.md](../../ToDo.md). The interface translation and subtitle-translation features below are not currently available.

## Interface translations — planned

The plan is to make the app's buttons, menus, and messages available in more than one language. Italian and Lithuanian are specifically listed in the backlog. This would translate the app itself; it would not automatically translate a movie's dialogue.

## Language defaults — planned

A language settings screen would let each user choose an interface language and preferred languages for audio and subtitles. It would also let the user decide whether subtitles should start enabled.

Some language behavior already exists: playback can match audio to browser language preferences, the player lets you select tracks, and subtitle preferences can be remembered for an account and title. The planned work adds explicit, central settings. See [Audio, subtitles, and video compatibility](audio-subtitles.md) for what works today.

## Automatic subtitle translation — planned

The backlog proposes using a language model to translate subtitle text. For example, it could make subtitles understandable when a source does not include the viewer's language. There is no implemented translation service or selection screen to use today; provider choice, cost, and quality are not specified in the task list.

## Subtitles for language learning — planned

Another idea is to translate only part of the subtitles. A learner could read mostly familiar text while seeing a few words in the language they are learning, or do the reverse as they become more confident.

This is a separate idea from ordinary subtitle language selection. No learning mode is currently implemented.

## Follow the plan

The [Language, Auto-translation, and Language learning sections of ToDo.md](../../ToDo.md#language) track these ideas. The backlog does not give delivery dates.
